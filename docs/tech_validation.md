# 技术验证报告

> 第 11 周提交物 · `docs/tech_validation.md`
> 验证环境：Windows 11 · Python 3.13 · 无 LLM 密钥（离线降级模式）· edge-tts（联网）

## 1. 验证目标

| # | 待验证技术 | 验证问题 | 结论方向 |
| --- | --- | --- | --- |
| V1 | 端到端 Agent 流水线 | 创意→检索→写作→配图→配音→短片→绘本能否一条命令跑通，产物是否齐全有效 | 采纳/放弃 |
| V2 | 离线模板创作器（降级方案） | 无密钥时故事质量是否可用、输出是否确定（可测试） | 采纳/放弃 |
| V3 | 本地程序化插画 + 角色一致性 | 固定 seed + 特征卡能否让角色跨场景可辨认同一人 | 采纳/放弃 |
| V4 | edge-tts 多角色配音 + 句级时间轴 | 音色区分、时间轴能否驱动视频字幕对齐 | 采纳/放弃 |
| V5 | ffmpeg（imageio-ffmpeg 免安装）合成短片 | 音画同步、字幕烧录 | 采纳/放弃 |
| V6 | 干预最小重算逻辑 | 改名/改场景后重算集是否符合"最小受影响"预期 | 采纳/放弃 |

## 2. 验证步骤与结果

### V1 端到端流水线 ✅ 采纳

- 步骤：`python src/prototype/run_prototype.py`（创意"一段关于勇气的小小太空冒险"，主角朵朵，6 场景）
- 结果：6 个工具步骤全部 `done`，端到端 **173.9 秒**（其中 TTS 逐句合成约 150 秒）
- 产物清单（均为真实文件，非占位）：

| 产物 | 文件 | 规格 |
| --- | --- | --- |
| 故事 JSON | `data/stories/prototype_story.json` | 6 场景 / 2 角色 / schema 校验通过 |
| 插画 ×6 | `outputs/images/scene01..06.png` | 1280×720 PNG |
| 有声书 | `outputs/audio/prototype_audiobook.mp3` | **148.02 秒**，27 句，3 音色，含 BGM |
| 时间轴 | `outputs/audio/prototype_audiobook_timeline.json` | 句级 start/dur/speaker |
| 短片 | `outputs/video/prototype_video.mp4` | 1280×720 H.264+AAC，字幕烧录 |
| 绘本 | `outputs/book/prototype_book.pdf` | 8 页（封面+6 幕+寓意页） |

### V2 离线模板创作器 ✅ 采纳

- 确定性：同输入两次生成 JSON **逐字节一致**（`True`）——单元测试可精确断言；
- schema 通过率：5 组不同创意（太空/森林/海洋/城市/沙漠）**5/5 通过**；
- 质量人工评估：六幕情绪弧完整，文本通顺可读；局限是措辞模板化、惊喜感弱于在线 LLM。定位为"降级可用"而非"同等替代"。

### V3 本地插画 + 角色一致性 ✅ 采纳

- 方案：全局固定 `seed=20261109` + 角色特征卡（发色/服装色/比例/位置锚点）；
- 结果：6 个场景中主角朵朵（蓝衣黄巾、固定锚点）与光团伙伴布布（暖黄光晕）形象逐场景一致，肉眼可辨认为同一角色；场景差异仅来自背景图层（星空/行星/丘陵）；
- 结论：离线一致性达标；在线文生图（dashscope）接口已预留，接入后方案不变（同 seed + 同特征卡注入 Prompt）。

### V4 TTS 多角色 + 时间轴 ✅ 采纳（附工程修复）

- 首轮运行发现 **Bug-T1**：edge-tts 偶发返回"No audio was received"，原实现一句失败即全局降级为静音 → 有声书无语音；
- 修复：① 每句重试 2 次；② 单句失败只降级该句（静音占位+时长估算）；③ 连续 3 句失败才判定断网；④ 停顿改为本地静音 WAV，不再消耗 API；
- 修复后复测：27/27 句合成成功，说话人分布 旁白13 / 朵朵12 / 布布2，时长 148.02s 与时间轴一致。

### V5 短片合成 ✅ 采纳

- 方案：timeline 驱动每句一帧（PIL 烧字幕）→ ffmpeg concat 一次合成；
- 结果：`prototype_video.mp4` 2.5MB，画面-配音-字幕逐句对齐（同一时间轴驱动，无累计漂移）；
- imageio-ffmpeg 自带静态 ffmpeg 二进制，**免安装 ffmpeg**，验证通过。

### V6 干预最小重算 ✅ 采纳（逻辑层）

- "把主角改成朵拉" → 解析 `{protagonist: 朵拉}` → 重算集 `[voice, compose_video, build_book]`（插画复用，符合预期）；
- 二次干预"场景改成森林" → 重算集为全链 5 工具（场景变了图必须重画，符合预期）；
- 端到端干预实跑安排在第 12 周 MVP（Web 交互）一并验证。

## 3. 采用结论汇总

| 技术 | 结论 | 备注 |
| --- | --- | --- |
| Agent 循环 + 工具注册表 | ✅ 采用 | 规划器可插拔已实现 |
| 离线模板创作器 | ✅ 采用 | 作为 mock provider 与降级链末端 |
| 本地 PIL 插画（seed+特征卡） | ✅ 采用 | 在线文生图接口预留 |
| edge-tts + 句级时间轴 | ✅ 采用 | 含重试/降级加固 |
| imageio-ffmpeg 合成 | ✅ 采用 | 免安装 ffmpeg，部署成本大幅降低 |
| 标准库 http.server Web UI | ⏳ 第 12 周验证 | 属 MVP 范围 |

## 4. 遗留风险

1. 在线 LLM/文生图路径本机无密钥未实测，第 12 周起配置密钥补测（离线降级保证演示不受影响）；
2. edge-tts 依赖微软服务可用性，现场演示需准备离线降级预案（已内建）；
3. 模板创作器文本在长创意下偶有句式重复，第 13 周测试阶段评估是否需要扩充变体库。
